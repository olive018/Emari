Put the lesson GIFs in this folder, using exactly these file names.
(If a file is missing, the lesson window shows a placeholder with the file name, so nothing breaks.)

Tips: 3-6 second loops, about 800 x 600 px, ideally under 2 MB each.

SOLAR
  solar-1-sunlight.gif   Sun rays hit a cell; a photon knocks an electron loose and leaves a "hole"
  solar-2-current.gif    Electrons flow along the grid lines, through a wire and back in a loop (DC)
  solar-3-inverter.gif   Flat DC line goes into a box and comes out as a smooth AC wave
  solar-4-use.gif        Power goes to the building; extra goes to a battery or grid; arrows reverse at night

RAINWATER
  rain-1-catchment.gif   Rain lands on the roof and slides to the edges; litres counter ticks up
  rain-2-pipes.gif       Water runs along the roof-edge pipes toward the tank; mesh guard catches a leaf
  rain-3-filter.gif      Dirty first flush diverted away; clear water passes through mesh, gravel and sand
  rain-4-storage.gif     Tank fills; when full, extra water flows out of the overflow into the soil

To change a file name, edit the "gif" line for that step in lessons.js.
